Competency survey pipeline

Tools for the survey and qualitative work in a competency assessment: review an instrument, code open-ended comments against a codebook, and find where training should go first. Load a sample or your own Qualtrics export.

The samples are synthetic (120 simulated respondents). Nothing comes from the IMLS project or real librarians. Files you load stay in your browser: nothing is uploaded anywhere.

What the three tools do

  1. Instrument reviewFlags weak, redundant, reverse-worded, skipped and ceiling items, and says what to change. Try the pilot sample with deliberate flaws.
  2. Coding workbenchEdit a codebook and watch open-ended comments get coded live, with kappa against a human coder and the words your codebook is missing.
  3. Gap explorerShows which groups are weakest on which competencies, so training goes where it is needed.

The analysis below was run in Python on the synthetic sample. The tools above run the same kinds of checks in the browser on any CSV, including a Qualtrics export.

Reproduce and reuse

Run python generate_synthetic_data.py then python analyze.py, then python build_site.py to rebuild this site. Outputs include a de-identified dataset and a data dictionary for sharing and preservation.

Instrument review

Checks every item for the problems that make a survey hard to interpret, then lists what to reword, reverse-code, merge or drop. Try Load pilot with problem items to see it flag four deliberately flawed draft items.

Coding workbench

Each code is a list of comma-separated terms. A term matches the start of a word, so statistic finds "statistics". Edit the terms and every result updates. The tool suggests; the human coder decides.

Gap explorer

Average rating for each group on each item. Shading shows distance from the overall average, so the weakest spots stand out. Groups with fewer than 5 respondents are faded.
